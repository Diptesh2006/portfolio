# Diptesh Das portfolio

A fast, static portfolio for GitHub Pages. The site is built with plain HTML, CSS, and JavaScript, with no build step or framework dependency.

## Local preview

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Content source

The portfolio content is based on the current `Diptesh-Das-Resume.pdf`. The older resume was removed so the site has one source of truth for experience, projects, skills, and credentials.
